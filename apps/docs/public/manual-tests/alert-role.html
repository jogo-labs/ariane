Mode d'emploi
  1. Cette page charge le composant tel que construit pour ce déploiement (bundle indiqué ci-dessus).
  2. Pour comparer avec l'ancienne implémentation (rôle posé par attribut), ouvrir la page avec ?bundle=https://unpkg.com/@ariane-ui/core@0.1.0-alpha.14/cdn/index.js.
  3. Lecteurs d'écran à essayer : VoiceOver (Safari, Chrome), NVDA (Firefox, Chrome), JAWS si disponible. Écouter pour chaque scénario et reporter le résultat en bas de page.
  4. Vérification dans l'outil de développement : onglet « Accessibilité » de Chrome, rôle calculé de chaque ar-alert. Une alerte error doit être alert, une info doit être status, et l'attribut role correspondant est écrit par le composant sur l'élément (visible dans l'inspecteur du DOM).

Les blocs en pointillés sont des témoins natifs (un <div role="…"> ordinaire) : si le lecteur d'écran ne les annonce pas non plus, le silence ne vient pas du composant.
