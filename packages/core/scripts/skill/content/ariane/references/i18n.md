# Traductions

## Composants localisés

Les libellés accessibles (annonces `aria-live`, `aria-label`, textes de boutons) de ces composants sont traduits, d'après le marqueur `x-localized` du CEM :

`ar-alert`, `ar-breadcrumb`, `ar-charcounter`, `ar-datepicker`, `ar-dialog`, `ar-pagination`, `ar-spinner`, `ar-stepper`, `ar-table-sort`.

- Les autres composants n'ont aucun libellé traduit (par exemple `ar-progressbar` : libellé fourni par slot).
- Les traductions `fr` (défaut) et `en` sont embarquées dans chaque composant concerné (CDN ou npm) : aucun import supplémentaire pour les utiliser.
- Mécanisme : `@shoelace-style/localize`.

## Fournir une traduction

Pour une langue absente ou pour remplacer `fr`/`en` : enregistrer un objet `Translation` avec `registerTranslation`, depuis `@ariane-ui/core/utils` (n'enregistre aucun composant).

```ts
// es.ts
import { registerTranslation } from '@ariane-ui/core/utils';
import type { Translation } from '@ariane-ui/core/utils';

const translation: Translation = {
    $code: 'es',
    $name: 'Español',
    $dir: 'ltr',

    // ... tous les termes, traduits
    sortPending: '...',
    loading: '...',
};

registerTranslation(translation);

export default translation;
```

- `$code` : code de langue qui doit correspondre à `lang`. `$name` : nom de la langue. `$dir` : `'ltr'` ou `'rtl'`.
- Le type `Translation` impose de fournir tous les termes (un seul type plat pour tous les composants). Le tableau ci-dessous liste les termes attendus (noms et arguments) ; traduire chacun. Les traductions `fr` et `en` n'ont pas d'export public : elles ne sont pas importables pour servir de base.
- Termes qui sont des chaînes : `string`. Termes qui sont des fonctions : à implémenter, ils reçoivent les arguments indiqués.

| Composant        | Termes (type)                                                                                                                                                                                                                                                                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ar-table-sort`  | `sortAscending(type)`, `sortDescending(type)`, `sortReset(type)` (`type` : `TableSortType`), `sortPending`, `sortInProgress`, `sortApplied(columnLabel, order)`, `sortFailed(columnLabel)`                                                                                                                                                             |
| `ar-datepicker`  | `today`, `close`, `closeCalendar`, `openCalendar`, `selectDate`, `previousYear`, `previousMonth`, `nextMonth`, `nextYear`, `daySelected(formattedDate)`, `expectedFormat(format, example)`, `availableDates(range)`, `dateRangeBetween(from, to)`, `dateRangeFrom(from)`, `dateRangeUntil(to)`, `formatOrdinalDate(date, monthYearText, fullDateText)` |
| `ar-pagination`  | `previousPage(page, total)`, `nextPage(page, total)`, `pageStatus(page, total)`, `compactPageStatus(current, total)`, `goToPage`, `paginationLandmark(page, total)`                                                                                                                                                                                    |
| `ar-stepper`     | `stepperNavLabel`, `stepLabel(order, isSubstep)`, `currentStepStatus(current, total)`                                                                                                                                                                                                                                                                  |
| `ar-breadcrumb`  | `breadcrumbNavLabel`, `showBreadcrumb`                                                                                                                                                                                                                                                                                                                 |
| `ar-charcounter` | `remainingLabel`, `excessMessage(count)`                                                                                                                                                                                                                                                                                                               |
| `ar-spinner`     | `loading`, `loadingDone`                                                                                                                                                                                                                                                                                                                               |
| `ar-dialog`      | `closeDialog`, `closingBlocked`, `dialogDefaultLabel`                                                                                                                                                                                                                                                                                                  |
| `ar-alert`       | `closeAlert`                                                                                                                                                                                                                                                                                                                                           |

- `formatOrdinalDate` : `monthYearText` et `fullDateText` sont déjà formatés par `Intl` ; le terme décide seulement d'un éventuel marqueur ordinal (« 1er » en français).
- L'exemple ci-dessus (import depuis `@ariane-ui/core/utils`) vaut pour les composants chargés par npm. Il ne convient pas aux composants chargés en CDN : sans bundler, `@ariane-ui/core/utils` ne se résout pas dans le navigateur ; avec un bundler, il embarque une seconde copie du registre des traductions, que les composants CDN ne lisent pas (échec silencieux : les composants ne voient pas la traduction et utilisent la langue de repli).
- En CDN, importer `registerTranslation` depuis la même URL et la même variante (`.dev.js` ou non) que les composants : `cdn/index.js` (ou `cdn/index.dev.js`) l'exporte et partage le registre des traductions avec les composants chargés par l'autoloader de la même variante. Importer `cdn/index.js` enregistre aussi tous les composants (bundle complet).
- Poser `lang` sur `<html>`.

```html
<html lang="es">
    <head>
        <script type="module">
            import { registerTranslation } from 'https://unpkg.com/@ariane-ui/core@<version>/cdn/index.js';

            registerTranslation({
                $code: 'es',
                $name: 'Español',
                $dir: 'ltr',

                // ... tous les termes, traduits
                sortPending: '...',
                loading: '...',
            });
        </script>
        <script
            type="module"
            src="https://unpkg.com/@ariane-ui/core@<version>/cdn/autoloader.js"
        ></script>
    </head>
    <body>
        <ar-table-sort>Precio</ar-table-sort>
    </body>
</html>
```

## Langue par défaut

Ordre de résolution de la langue d'un composant :

1. Attribut `lang` sur le composant lui-même.
2. Attribut `lang` de `<html>`.
3. Langue du navigateur (`navigator.language`) si aucun des deux n'est présent.

- Seuls `<html lang>` et le `lang` posé directement sur le composant comptent : un `<div lang="es">` autour d'un composant n'a aucun effet (pas de traversée du DOM à chaque rendu).
- Si aucune traduction n'existe pour la langue résolue, le français est utilisé. La langue de repli est la première traduction enregistrée (`fr`).
- `lang` pilote aussi le formatage `Intl` ; il n'existe pas de propriété `locale` séparée.
- Les variantes régionales (`en-GB`…) ne sont pas fournies : seules `fr` et `en` existent.

```html
<!-- Langue par défaut de la page -->
<html lang="en">
    <!-- Ou par composant, en surcharge -->
    <ar-table-sort lang="es">Prix</ar-table-sort>
</html>
```
